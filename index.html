Activity Title

Hotel Room Booking System

Objective

Create a C program that determines whether a hotel can accommodate a guest based on the number of guests and the guest's preferred room type. The program must use nested if-else statements.

Scenario

A small hotel offers Standard and Family rooms. The type of room that can be booked depends on the number of guests. Your program will help the receptionist determine which room can accommodate the customer.

Instructions

  1. Ask the user to enter the number of guests.
  2. If there are 1 or 2 guests, ask the customer to select:
    • 1 - Standard Room — ₱1,500 per night
    • 2 - Family Room — ₱2,500 per night
  3. If there are 3 or 4 guests, only a Family Room can accommodate the group.
  4. If there are more than 4 guests, the hotel cannot accommodate the group in a single room.
  5. Use nested if-else statements to determine the appropriate result.

Program Conditions

1 to 2 Guests

Ask the customer to choose a room type.

  • If the customer selects 1, display:
    Standard Room booked - P1500 per night.
  • If the customer selects 2, display:
    Family Room booked - P2500 per night.
  • Otherwise, display:
    Invalid room selection.
3 to 4 Guests

Ask the customer if they agree to book a Family Room.

  • Enter 1 for Yes.
  • Enter 0 for No.

If the customer agrees, display:
Family Room booked - P2500 per night.

Otherwise, display:
Booking cancelled.

More Than 4 Guests

Display:

Group cannot be accommodated in a single room.

Example Output 1

Enter choice: 1

Example Output 3

HOTEL ROOM BOOKING SYSTEM

Enter number of guests: 6

Group cannot be accommodated in a single room.

Programming Requirements

  • The program must be written in C.
  • The program must use nested if-else statements.
  • Do not use a switch statement.
  • Use appropriate variables for the required inputs.
  • Display clear and understandable messages to the user.
  • The program should reject a number of guests that is 0 or below by displaying Invalid number of guests.
Reminder: Do not ask every question immediately. Some questions should only appear after a previous condition has been satisfied. This is the purpose of using a nested if-else structure.
